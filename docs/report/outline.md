# College report outline

1. Title page, abstract, and objectives
2. INS syllabus connection: remote user authentication and trusted third parties
3. Background: Needham–Schroeder, Kerberos roles, tickets, and authenticators
4. Problem statements and related work (established risks, no novelty overclaim)
5. Architecture, threat model, trust boundaries, and simulation simplifications
6. Baseline authentication implementation
7. Replay experiments: synchronized clocks, simulated skew, and defenses
8. Synthetic Kerberoasting extension: weak versus random service passwords
9. Experimental method, actual measurements, and before/after comparisons
10. Limitations: educational wire format, local transport, crypto/KDF choices, cache behavior, bounded wordlist
11. Conclusion and future work
12. References and reproducible run instructions

Write the abstract and conclusions after the experiments, so they describe the implemented system and observed results.
