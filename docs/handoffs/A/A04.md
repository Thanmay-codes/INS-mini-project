## TDD and observed behavior

The user requested TDD; the previously agreed frozen A01 factory/HTTP/process interfaces are the test seams. Observed red→green slices: valid access (missing settings/clock-aware factory), defended duplicate (incorrect second grant), CLI controls (missing implementation). Adversarial and process regressions were added after these capability slices and passed on the implemented shared-helper path; not every parametrized case was observed failing first.

Checks establish:

- Exact resource success/error and implemented health shapes; counter commits; duplicate JSON/content type/size/query/schema/version/value rejection; framework 404/405 retained.
- Both modes reject changed MAC, identity, service, ticket ID, method, path, body digest, ticket digest, encrypted ticket, wrong key, TGT role and unsupported client. Invalid requests do not change the counter or reserve a valid request's nonce.
- Fresh authenticated nonces on the same ticket succeed. Reformatting JSON does not avoid defended duplicate checks. No-cache does not reserve identities, remains able to execute at replay-capacity exhaustion, and still needs healthy operation state.
- Inclusive not-before/expiry leeway and authenticator skew boundaries; invalid/expired authentication takes priority over replay classification. The request uses one captured clock reading.
- Missing/corrupt/mismatched state gives 503 at access, required state is never recreated, and startup fails without initialized material/store. Capacity rejects new work; duplicate classification remains 409 at capacity. A held SQLite writer lock gives 503, then the same request succeeds after release. Injected counter overflow rolls back replay consumption, allowing successful retry after the injected fault is removed.
- Two spawned HTTP worker processes sharing the same run accept exactly 3 distinct identities from 6 concurrent requests in defended mode (3 duplicate rejections), with committed counters 1–3. After both exit, a fresh process rejects the original request and retains counter=3. No-cache accepts all 6 with counters 1–6, then replay after restart commits counter=7.
- Actual `python -m kerberos_lab.resource_server.app` startup honors TOML settings and CLI precedence for defense mode, port, frozen time and offset; its help/required flags and safe startup failure are tested. Fixed loopback host has no user-supplied host flag.
