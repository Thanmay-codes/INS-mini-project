## Completed deliverables

- `experiments/analysis/analyze.py` validates the B03 JSONL/CSV/environment bundle, reconciles attempt, decision, trial and failure counts, then produces denominator-aware scenario, primary-metric, time-category and performance summaries. It rejects malformed/mismatched inputs instead of silently dropping them.
- Duplicate acceptance is measured only on the second exact E02 request. Legitimate rejection includes E01 and E03, treats HTTP 4xx/5xx as protocol rejections, and keeps status-0 transport failures separate. Restart replay, operation counts, time-check categories, requested/observed/missing/failed trials, request latency and per-trial startup are represented.
- Request p50/p95 use nearest rank `sorted[ceil(p*n)-1]`, without interpolation. Run-to-run variation is summarized by taking each trial's median latency (mean of the middle pair for even counts), then nearest-rank p50/p95 across those trial medians.
